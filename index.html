I am a student at Ateneo de Davao University. I built CodeNest as a place to practice programming and bring my school exercises together in one clean workspace, and also in complience with my Intro To Programming Subject.

Purpose of this project

CodeNest is a JavaScript utility dashboard. Each tool is a small program that applies a core idea I am learning, so I can understand the logic instead of only memorizing it.

  • ⇄ Conversion Calculator: practice with functions, formulas and input checking.
  • ₱ Income Tax Calculator: practice with conditions and tax brackets.
  • ⟳ Looping Exercises: practice with while, do-while and for loops.
  • ▤ Payroll Management: practice with arrays, objects and updating the page.
